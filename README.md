# Dograh Hybrid AI Telephony Engine 🚀🎙️

This is your free, 24/7/365 production-grade AI Voice Agent calling server deployed directly on Hugging Face Spaces.

## Features:
- **FastAPI / Uvicorn** AI Telephony Worker (running on port 7860).
- **Asterisk 20+** telephony server with secure WebRTC and SIP trunk dialing.
- **PostgreSQL** database & **Redis** cache running inside the same Space.
- Fully automated CI/CD pipeline via GitHub Actions.
